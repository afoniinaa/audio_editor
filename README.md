# Примитивный аудиоредактор

Инструмент для базовой обработки WAV-файлов.

## Возможности

- **Обрезка** – выделить фрагмент от начала до конца (в секундах) и сохранить его как новый файл.
- **Изменение скорости** – ускорить или замедлить воспроизведение.
- **Разделение на несколько дорожек** – разбить один аудиофайл на несколько независимых дорожек по заданным временным меткам.
- **Соединение дорожек** – объединить несколько аудиофайлов в один (последовательное склеивание).

## Поддерживаемые форматы

- **На данный момент:** `.wav`
- **В планах:** `.mp3`
